# Enda en?

Ansiktsskanneren som alltid gir grønt lys. Ren HTML/CSS/JS, ingen bygging nødvendig.

## Legg ut på GitHub Pages

1. Lag et nytt repo på GitHub og last opp **innholdet** i denne mappen (index.html skal ligge øverst i repoet).
2. Gå til **Settings → Pages**.
3. Under *Build and deployment* velger du **Deploy from a branch**, branch `main` og mappe `/ (root)`. Trykk Save.
4. Vent til kjøringen **pages build and deployment** under *Actions* er grønn, og åpne lenken du får der.

## Installer på telefonen

Åpne lenken i Chrome eller Samsung Internet, trykk på menyen og velg **Installer app** (eller *Legg til på startskjermen*). Ikonet er en øl med grønn hake.

Kameraet krever HTTPS, og det har GitHub Pages automatisk.
